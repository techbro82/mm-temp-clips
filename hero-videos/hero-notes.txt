MentorMind landing page hero ("Reach toward the wise,") - videos and posters
Source: mentormind-live/web/landing.html (read only). Copied unchanged, original file names.

HOW THE PAGE PICKS A FILE
An inline script in landing.html decides before the video has a source:
  phone version  if window.innerWidth <= 700, or the browser reports data saver on (any width)
  desktop version otherwise (this includes tablets wider than 700 px)
The <video> element: autoplay muted loop playsinline preload="auto"
  - It LOOPS forever (does not play once). It starts on its own, muted.
  - The poster image shows until the first frame is ready.

CSS THAT SIZES AND POSITIONS THE VIDEO (exact, from landing.html)

  .hero{position:relative;min-height:100vh;overflow:hidden;}
  .hero-video{position:absolute;inset:0;width:100%;height:100%;object-fit:cover;z-index:0;}

Same rule for phone and desktop. There is NO object-position set, so the browser default
(50% 50%, centred) applies. There is no separate phone rule for the video itself.
  object-fit: cover
  object-position: 50% 50% (default, not set in the CSS)
  width: 100%
  height: 100%  (of the .hero section, which is min-height: 100vh, so the full screen height)
  position: absolute; inset: 0; z-index: 0

What that means on a phone, for a 390 x 844 screen:
  The 540x960 clip is scaled until it covers the screen: scale = 844/960 = 0.879, so it is drawn
  about 475 x 844 px. The sides are cropped about 42 px each (about 9% of the width per side).
  Top and bottom are not cropped. The crop is centred.
  Wider phones (e.g. 430 x 932) crop the sides a little less; shorter or browser-bar-affected
  screens change it slightly because 100vh follows the browser's own viewport height.
